# 排盘规则规格书

## 文件作用

- 定义本项目“八字排盘”功能的统一计算口径。
- 作为前端实现、测试用例设计、后续规则扩展的基准文档。

## 目标

本规格书用于明确：
- 输入项
- 默认排盘规则
- 可配置规则
- 年柱、月柱、日柱、时柱确定方式
- 大运、流年、流月、流日、流时的范围
- 边界情况与争议点处理

本项目目标是做“主流口径、工程可实现、结果可测试”的排盘系统。

## 1. 产品范围

### 1.1 明确需要
- 公历输入
- 农历输入
- 农历闰月输入
- 四柱排盘
- 藏干
- 十神
- 五行统计
- 大运
- 流年
- 流月
- 流日
- 流时
- 规则配置

### 1.2 明确不做
- 时区输入
- 文案解释
- 合婚

### 1.3 默认产品定位
- 面向工具型排盘场景
- 默认采用主流排盘产品的常见工程口径
- 对争议规则提供配置能力
- 不在 v1 内做解释型内容

## 2. 输入规格

### 2.1 基础输入
- 出生日期：年、月、日
- 出生时间：时、分
- 性别：男 / 女
- 历法类型：公历 / 农历

### 2.2 可选输入
- 是否闰月（农历输入时）
- 姓名 / 标签 / 备注
- 规则配置（高级设置）

### 2.3 缺失时间处理
- 允许未知时辰模式
- 若未填写出生时间，则只计算年柱、月柱、日柱
- 时柱标记为未知
- 依赖时柱的结果不展示或标记不完整

### 2.4 内部标准化模型

```ts
interface BirthInput {
  calendarType: 'solar' | 'lunar'
  birthDate: string
  birthTime: string | null
  gender: 'male' | 'female'
  isLeapMonth?: boolean
  note?: string
}
```

## 3. 默认规则（V1）

### 3.1 年柱
- 默认按立春切换年柱

### 3.2 月柱
- 默认按节气切换月柱
- 采用“节”作为月份切换点

### 3.3 日柱
- 默认按本地标准时间 00:00 换日

### 3.4 时柱
- 默认按标准十二时辰划分
- 子时：23:00–00:59
- 丑时：01:00–02:59
- 寅时：03:00–04:59
- 卯时：05:00–06:59
- 辰时：07:00–08:59
- 巳时：09:00–10:59
- 午时：11:00–12:59
- 未时：13:00–14:59
- 申时：15:00–16:59
- 酉时：17:00–18:59
- 戌时：19:00–20:59
- 亥时：21:00–22:59

### 3.5 农历输入
- 农历仅作为输入方式之一
- 内部统一转换为标准计算输入后再排盘
- 必须支持闰月输入

---

## 4. 可配置规则

### 4.1 日界规则
支持以下配置：
- `midnight`：00:00 换日（默认）
- `zi-hour`：23:00 换日
- `split-zi-hour`：早晚子时

### 4.2 年界规则
v1 默认只提供：
- `lichun`：立春切年

如后续需要，可扩展其他口径。

### 4.3 月界规则
v1 默认只提供：
- `jieqi`：按节气切月

### 4.4 真太阳时
- v1 默认关闭
- 数据模型层预留能力
- 不作为当前首发必做功能

---

## 5. 四柱规则

### 5.1 年柱
- 以立春为切换点
- 立春前仍属上一干支年
- 立春及之后进入新干支年

### 5.2 月柱
- 以十二节为切换点
- 对应关系：
  - 立春起寅月
  - 惊蛰起卯月
  - 清明起辰月
  - 立夏起巳月
  - 芒种起午月
  - 小暑起未月
  - 立秋起申月
  - 白露起酉月
  - 寒露起戌月
  - 立冬起亥月
  - 大雪起子月
  - 小寒起丑月
- 月干按“年上起月”规则顺推

### 5.3 日柱
- 基于标准化日期求取日干支
- 要求与选定参考样例保持一致

### 5.4 时柱
- 时支按十二时辰确定
- 时干按五鼠遁，由日干推出子时天干后顺推

## 7. 参考策略

- 以当前主流排盘产品常见结果作为参考方向
- 不强绑定单一平台
- 实现阶段应挑选若干常见工具做交叉比对
- 最终以本项目测试样例为准

建议后续补充：
- 一组覆盖边界情况的标准出生样例
- 每个样例对应的四柱与流运期望结果

---

## 8. 工程要求

- 核心算法保持纯函数
- 争议规则集中在配置层管理
- UI 不直接承载排盘逻辑
- 边界计算必须有测试覆盖
- 所有规则变更必须同步更新本文件
