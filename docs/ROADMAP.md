- 定义输入输出模型

- 建立测试框架与基准样例

- 农历输入支持
- 闰月建模与转换

- 干支基础换算

- 四柱计算
- 藏干
- 十神
- 五行统计
- 时辰未知模式

## Phase 4: 流运能力
- 大运基础版
- 流年
- 流月
- 流日
- 流时
- 规则切换对流运结果的影响校验

## Phase 5: 产品化增强
- 结果页优化
- 配置项面板
- 历史记录 / 最近使用

- 导出 / 分享
- 对比不同排盘口径
